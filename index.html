    Configuración de API

    Clave de API de Gemini

    Para realizar investigaciones profundas reales y búsquedas web en tiempo real, necesitas ingresar una clave API oficial de Google Gemini.

    Privacidad BYOK: la clave no se envía a DropDeep. Solo viaja a Google (generativelanguage.googleapis.com) desde tu navegador, o al proxy Supabase si usas sesión sin BYOK. Se guarda en localStorage de este dispositivo.

    Nota de seguridad: En modo BYOK la clave vive en tu navegador y no se envía a los servidores de DropDeep — solo a Google. Con proxy Supabase (VITE_GEMINI_PROXY) usas la clave del servidor tras iniciar sesión; tu BYOK no viaja al proxy si está guardada (prioridad BYOK).
